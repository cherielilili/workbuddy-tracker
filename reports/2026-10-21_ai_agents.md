# AI Agent 赛道日报 2026-10-21

## 摘要
腾讯 WorkBuddy 发布 5.8.3 补丁版，集中于运行时闪屏、账号串号与语音功能异常的修复，并优化沙箱内存与代理连接稳定性。OpenClaw 连续推送 2026.10.10-beta.3，主线仍是 Windows 可靠性、升级恢复与 Agent 状态一致性。Stanford HAI 上线医疗 AI 评测方法论长文，并挂出 AI100 第三份报告《AI Goes Mainstream》的 11 月发布场次及多场 AI 经济相关研讨。

## 重大信号
- **[Stanford HAI]** AI100 第三份报告《AI Goes Mainstream: The Scaling Era and the Rise of Generative AI》定档 11-18 公开讲座，研究小组由 Michael Wooldridge 领衔，内容覆盖 Scaling 时代与生成式 AI 主流化路径，属年度旗舰报告级别发布。 https://hai.stanford.edu/events

## 腾讯 WorkBuddy
- 更新日志新增 **5.8.3 版本（2026-10-19）**：修复内置运行时随版本切换弹出的闪屏、账号刷新串号导致会话错乱、企业微信助理会话结束入口回路异常，以及 5.8.3 中语音功能被异常覆盖导致不可用的问题；同时优化本地沙箱内存占用（修复长期运行内存膨胀卡死）、企业代理与系统证书环境下的连接稳定性。 https://www.codebuddy.cn/docs/workbuddy/Changelog
- 腾讯云开发者社区 10-19 出现新横评文《开源AI工作台实测：和 WorkBuddy 到底差多少？》，从技能市场、办公生态集成（腾讯文档/会议/企微/邮箱/乐享）、计费模式三个维度对比开源 AI 工作台，认为 WorkBuddy 优势集中在运营化技能市场与国内办公链路整合，短板是定制需求需等官方排期；另有 07-21 老帖阅读量升至 1.6K，仍是重度办公场景短板讨论。 https://cloud.tencent.com/developer/search/article?q=WorkBuddy

## Open Source / OpenClaw
- 发布 **openclaw 2026.10.10-beta.3（10-21）**：Windows 侧恢复全新状态初始化与 Gateway 启动、隐藏 SQLite 辅助窗口、容忍强制重装的启动器时间戳；升级恢复逻辑收敛 app-owned 插件至升级后核心版本、修复 schema 变更后 agent store（含 held system agents）丢失、迁移回滚备份范围收窄到版本化表。
- 功能修复：并发初始化下两个 Agent 争抢同一 agent 数据库、Codex 与原生应用上下文刷新后阻塞回复、Discord 频道与线程的原生斜杠命令恢复、限流重试时保留 prompt cache、Gateway 重启后 CLI 会话工具目录失效导致 exec 等工具不可用、冷启动不再打开全部记忆索引、macOS 长命令 20 秒超时等。 https://github.com/openclaw/openclaw/releases
- 发布列表同步出现稳定版 **2026.10.5** 与 **2026.10.10-beta.2**，说明 10.10 系列正从 beta.1 快速迭代走向收敛。
