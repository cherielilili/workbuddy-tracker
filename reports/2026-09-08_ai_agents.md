# AI Agent 赛道日报 2026-09-08

## 开源 / OpenClaw
- **2026.9.3 版本发布（09-08）**：核心与插件更新可在隔离候选状态中预演后再激活，支持 2026.9.2 迁移与废弃更新记录恢复；性能上保留热提示缓存、降低冷会话更新与记忆搜索开销。
- Skill Workshop 改为每个 Agent 持有的持久技能集合，跨工作区共享，支持完整技能说明对比与 Doctor 安全退役。
- 浏览器标签页支持原生 Mac 窗口驻留；Models 设置中可直接管理已连接账号与优先级。
- 新增会话公开分享：可发布可撤销的只读视图；新增可搜索会议库（全文检索、Markdown/JSONL 归档下载）；新增可选团队活动报告（GitHub/Discord 活动浏览与模型摘要）。
- **破坏性变更**：要求 Node 24.16.0+ 或 26.1.0+（Node 22/25 不再支持，需先升级以避免 SQLite 文本截断）；execution-policy、approval、SDK 别名、搜索/目录结果回调、MCP prompt 适配器等多处 SDK 迁移。来源：https://github.com/openclaw/openclaw/releases

## 阿里 / QwenPaw
- **v2.2.1-beta.1 预发布（09-08）**：新增 Agent 模型路由设置；记忆模块升级 ReMe 至 0.4.1.11 并引入可选 PowerContext 可插拔长期记忆后端；治理层要求非自动拒绝的关键发现必须经审批。
- Creator 升级至 1.2.0：蓝图工作台、运行时通知总线与异步委托、多时间线 A/B 对比、自定义视频模板、MiniMax H3 视频、快照回滚与 Docker 部署。
- 其他：MCP 按工具白名单强制执行、Agent 受保护执行契约、上下文压力下折叠已消耗思考、Console 侧栏与设置体验重设计、技能工作区级预加载配置、单元测试覆盖率提升约 5 个百分点。来源：https://github.com/agentscope-ai/QwenPaw/releases
