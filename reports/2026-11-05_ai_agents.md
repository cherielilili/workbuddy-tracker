# AI Agent 赛道日报 2026-11-05

## 摘要
今日赛道动态密集：腾讯 WorkBuddy 灰度发布 5.11.0，首页大改版并全面升级定时任务；开源 OpenClaw 发布 2026.11.1 稳定版，聚焦会话可靠性、更新恢复与安全边界；Manus 官方复盘用 Manus 重建 Manus 的工程实践；阿里 QwenPaw 推送 v2.3.0-beta.2；Stanford HAI 新增多场重量级公开讲座，含 OpenAI 研究加速内部视角与 Brynjolfsson 参与的 AI 与劳动力研讨。

## 重大信号
- [Tencent] WorkBuddy 5.11.0 灰度发布：首页全新改版，定时任务全面升级（https://www.codebuddy.cn/docs/workbuddy/Changelog）
- [Manus] 官方博客发布《Rebuilding Manus with Manus》，披露用自家 Agent 重建产品的工程实践（https://manus.im/blog）
- [OpenClaw] 2026.11.1 稳定版发布：渠道回复可靠性、会话抗中断、更新恢复与安全修复（https://github.com/openclaw/openclaw/releases）
- [Stanford HAI] 新增 11-16 Christopher Ong 公开讲座《Research Acceleration: The View Inside OpenAI》，讨论 AI R&D 自动化（https://hai.stanford.edu/events）
- [Stanford HAI] 新增 11-13 特别研讨《Understanding Work Using AI》，Erik Brynjolfsson、Diyi Yang 与美国 O*NET 中心合作对谈（https://hai.stanford.edu/events）

## 腾讯 WorkBuddy
- **5.11.0 版本（2026-11-03，灰度中）**：首页全新改版，下线办公/开发/设计入口，统一任务栏、菜单与顶栏；定时任务全面升级，支持立即运行、编辑、重命名、删除与启动/暂停；独立文件浏览器支持标签页拖出独立窗口与右侧栏预览；频道 IM 新增组件化消息卡片与自定义表情包，消息跨端同步；创意设计接入图片编辑，图片视频产物统一在画布打开并默认入库；另修复云电脑、频道、资料库等若干问题。来源：https://www.codebuddy.cn/docs/workbuddy/Changelog

## Manus
- **《Rebuilding Manus with Manus: What changed, what broke, and how we work now》（2026-10-30）**：官方产品博客复盘用 Manus 自身重建 Manus 的过程，披露架构变化、踩坑与新的工作方式，是 Agent 自我托管（dogfooding）的标志性案例。来源：https://manus.im/blog

## 阿里 QwenPaw
- **v2.3.0-beta.2 预发布（2026-11-02）**：channels 抽取为插件并以子进程隔离；console 新增未读推送过滤、记忆文件按标签浏览；网站新增 JSON 驱动的评测索引；修复 skill 选择、媒体预览、thinking 开关、Windows 安装器、Code Mode 安全审批误报等大量问题。来源：https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw（开源）
- **2026.11.1 稳定版（2026-11-05）**：Mac 设置更安全，配置保存失败不再覆盖密钥，关闭 Tailscale 暴露时保留 Gateway 认证；Telegram、Discord、webhook 会话回复更可靠；超长轮次保留有效历史、Claude CLI 首轮流中止不再从零开始；更新器崩溃/取消后可恢复，Windows Gateway 验证失败后可还原；子代理在模型与会话变更后保留后续跟进；Android End Talk 不再取消已接受的 Agent 工作；Provider 恢复遵循限流时序，Gemini Flash 官方端点默认走 Interactions；Claude CLI 保存的订阅账号可直接提供模型，可通过配置选择性启用 Anthropic 原生 Agent/Workflow 编排；另含 ClickClack/ClawHub 重定向防护、日志脱敏等多项安全修复。来源：https://github.com/openclaw/openclaw/releases
- 预发布线同步推进至 2026.11.5-beta.1。

## 行业观察（53AI）
- **《从OpenClaw，怎么走到了Super Agent？》（2026-11-03）**：腾讯游戏数据团队负责人撰文，梳理从 Bot 形态到桌面/IDE 类 Agent、再到两类融合演进为 Super Agent 的路径，核心驱动是 Agent 贴近真实工作场景并可随时调用、共享能力。来源：https://www.53ai.com/news/Openclaw/
