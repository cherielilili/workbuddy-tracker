# AI Agent 赛道日报 2026-08-07

## 摘要
阿里 QwenPaw 今日发布 v2.1.0-beta.2 预发布版，带来多模态生成套件、DAG 调度器与 QwenPaw OS Shell 等重量级能力，为本日最重要动态。OpenClaw 推出 2026.7.1 稳定补丁线，腾讯 WorkBuddy 连发三个修复版本并上线官网登录跳转与 Ardot 占位图模式，Manus 接入 ElevenLabs 语音能力。Stanford HAI 连发三篇研究与政策文章，聚焦 AI 陪伴心理健康、开源权重模型之争与世界模型治理。

## 重大信号
- [Alibaba] QwenPaw v2.1.0-beta.2 预发布版上线：新增创作者多模态生成套件、DAG 调度器、动作引擎、时间线工作台，以及 QwenPaw OS Shell、文件工作区应用、ACP 可移植运行时会话、统一应用市场等大量能力（https://github.com/agentscope-ai/QwenPaw/releases）
- [Stanford HAI] 发布世界模型治理政策文章《Why Governing World Models Is AI's Next Big Policy Challenge》，警示世界模型带来的治理挑战超过大语言模型，政策窗口正在关闭（https://hai.stanford.edu/news）

## 腾讯 WorkBuddy
- 官方 Changelog 连发三个版本：v5.3.8（07-30）优化 macOS 文件系统性能、修复产物索引膨胀导致历史任务无法恢复等问题；v5.3.7（07-29）修复小程序推送、Deeplink 工作目录、SSE 中文乱码等约 30 项问题；v5.3.6（07-28）新增官网登录无缝拉起桌面端能力，Ardot 设计画布新增真实图片与文本占位图两种模式（占位图不消耗生成额度）（https://www.codebuddy.cn/docs/workbuddy/Changelog）
- 腾讯云开发者社区新增两篇用户内容：07-31《WorkBuddy 轻松工作》分享用 Skill 实现 PDF 技术通知单自动检索并生成手机可读链接；08-05 开发者分享使用 WorkBuddy 做项目开发的体验，认为其结构化需求理解力稳定（https://cloud.tencent.com/developer/search/article?q=WorkBuddy）

## Manus
- 08-03 发布《Introducing ElevenLabs on Manus: Give Your Ideas a Voice》，在 Manus 中集成 ElevenLabs 语音生成能力，可从单一对话为创意内容配音（https://manus.im/blog）

## 阿里 QwenPaw
- 08-07 发布 v2.1.0-beta.2 预发布版（今日）：核心亮点包括创作者多模态生成套件（含 DAG 调度器、动作引擎、grounding、时间线工作台与 i18n）、QwenPaw OS Shell、文件工作区应用、ACP 可移植运行时会话、统一应用市场列表、当前 Agent token 用量统计、统一项目目录与文件工作区加固，另含大量沙箱、记忆、桌面端 Chrome 通信修复（https://github.com/agentscope-ai/QwenPaw/releases）

## OpenClaw
- 08-04 发布稳定补丁线 2026.7.1-1 与 2026.7.1-2（标记 Latest）：修复 Codex 进度回复中断、Memory Core 启动死循环修复、WSL 状态权限、托管插件 npm 锁元数据恢复等问题；此前 08-02 还发布 2026.7.2-beta.7 预发布版（https://github.com/openclaw/openclaw/releases）

## Stanford HAI
- 08-04 三篇新文章：研究指出社交网络薄弱、向 AI 陪伴寻求情感支持的用户幸福感反而更低；James Landay 评论称开源权重模型之争方向有误，科学与社会需要真正开源的 AI 模型；政策文章呼吁尽快应对世界模型治理挑战（https://hai.stanford.edu/news）
