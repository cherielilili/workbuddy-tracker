# AI Agent 赛道日报 2026-08-08

## 摘要
今日赛道整体平稳，仅有两条小幅更新：腾讯 WorkBuddy 社区新增一篇选型对比实测，OpenClaw 发布 2026.6.34 稳定性修复版本。无重大信号。

## 腾讯 WorkBuddy
- 腾讯云开发者社区新增文章《WorkBuddy or Codebuddy》（2026-08-03）：作者对比 CodeBuddy 与 WorkBuddy 后选择专注 WorkBuddy，并分享通过切换到轻量模型（混元/GLM-5.1）可降低积分消耗 30%~50%。来源：https://cloud.tencent.com/developer/search/article?q=WorkBuddy

## OpenClaw
- 发布新版本 2026.6.34（2026-08-08）：强化浏览器与网络边界安全，沙箱化浏览器路由、可信 DNS 目标、自定义浏览器来源及环回 provider 端点均拒绝不安全访问路径；同时提升 agent 与 provider 运行的韧性（保留会话写入等）。来源：https://github.com/openclaw/openclaw/releases
