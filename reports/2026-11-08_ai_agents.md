# AI Agent 赛道日报 2026-11-08

## 摘要
今日赛道动态集中在开源 Agent 侧：OpenClaw 发布稳定版 2026.11.2，主线是隐私与信任边界收紧、账号安全投递、网关可用性与更新恢复的工程化修复，体现出头部开源 Agent 正从功能竞赛转向生产可用性与诊断数据治理。商业办公类与模型平台侧本周期无可读新增。

## 重大信号
- **[OpenClaw] 稳定版 2026.11.2 发布**：官方 releases 显示该版本已于 11-08 发布，重点是把配置密钥、会话内容、工具错误与渠道载荷移出诊断日志，强制所选 provider 与导航信任边界，并在 CLI 预热轮次结束后释放 MCP 授权；同时修复持久重试下的账号身份保持、网关阻塞、更新自锁与原生客户端重连等生产问题。（https://github.com/openclaw/openclaw/releases）

## OpenClaw
- **隐私与信任边界**：诊断日志不再记录配置密钥、会话内容、工具错误与渠道载荷；强制所选 provider 与导航信任边界；CLI 预热轮次结束后释放 MCP 授权（#191318、#174998、#174544、#172963、#174526、#173422、#191748、#191271、#193438、#191102、#191980）。
- **账号安全投递**：在持久重试与定时投递路径中保留发送者与账号身份；恢复 WhatsApp 身份查询；Teams 路由与允许列表设置在重载后保留。
- **网关可用性**：降低诊断采集开销，避免插件清理或异常 Telegram 表格阻塞网关；关闭流程中取消渠道启动，并恢复瞬时 schema-lease 冲突。
- **更新与恢复**：升级过程中保留已配置插件可执行文件与环境引用；修复 macOS 回收站访问被拒时的服务恢复；避免更新自锁与中断更新挂起。
- **原生客户端**：iOS 重连导航保持响应、Android 聊天启动态保留、Apple 模型与 computer-use 资源在瞬时初始化失败后可恢复。
- **模型路由与集成**：尊重禁用 reasoning、tier 后缀设置、别名与 catalog readiness；Codex 与 Claude 集成保留导入的登录态与工作区编辑，代理重启后保持原生线程。
- **记忆与嵌入**：限制组装后的召回上下文长度，接受 memory-search limit 别名，正确转发 Azure OpenAI embedding API version。
- **Agent 执行与诊断**：修复依赖环境的工具重试、流式参数退化、worktree 名校验；更新诊断避免 FIFO 挂起并以 JSON 报告向导失败。
- 预发布通道仍为 2026.11.5-beta.1，稳定线由 2026.11.1 升至 2026.11.2。
