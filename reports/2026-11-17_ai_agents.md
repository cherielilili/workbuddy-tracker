## Open Source / OpenClaw
- 稳定版 2026.11.5 于 11-17 10:47 发布，接替 2026.11.4，预发布 beta 线收敛为正式版。来源：https://github.com/openclaw/openclaw/releases
- 重启安全会话：排队消息、发送权限与最终聊天写入在 Gateway 重启后保留，减少重启导致的消息丢失与重复发送。
- 更新安全性：Doctor 或 Gateway 启动失败时自动回滚已激活的更新；恢复的 npm 包保持非 root 服务可读，降低升级失败导致的不可用风险。
- Telegram 渠道增强：交互式组件可在 Telegram 消息中渲染（含私聊 topic），并修复进度流模式下的 ACP 回复与审批落在私聊/论坛 topic 内的问题；被禁用的按钮渲染为非交互。
- 记忆与索引：大体积记忆索引重建可稳定完成，embedding 索引在网关截断批量错误后可恢复；知识页面增加读取预算与分段提取，避免加载超大页面。
- 模型回退可靠性：已配置的主账号不再阻断 Claude CLI 回退，OpenAI 会话可从压缩项冲突中恢复。
- 安全预设与忙碌会话：新增个人/企业两套安全预设提供一致默认值；个人模式下忙碌会话消息改为引导或静默排队，不再要求手动重发。
- 破坏性变更（集成方需迁移）：第三方 harness 必须在 host 的 runAttempt 回调中注册按会话键控的活动运行并保留返回的清理函数；插件 RPC 处理须改用授权 Gateway 方法分发替代 chatAbortControllers/chatQueuedTurns；start-owner 观测改用 startDeadlineAtMs。
- 运维类修复：cron 配置热重载不再中止在途任务、保留调度账号选择与重试截止时间；网关配置重载的文件监听竞态、MCP 监听在关机时取消等已修。
