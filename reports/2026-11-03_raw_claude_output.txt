技能链路：改用原生 skills CLI 完成校验与发布，GitHub 导入保留二进制文件，技能池下载支持可取消任务。\n- 控制台体验：新增未读推送消息过滤、按标签浏览记忆文件、工具卡图标裁切修复、会话切换时暂停侧栏轮询。\n- 模型与供应商：刷新非 OpenAI 模型目录与 provider 配置，修复 LLM 启动阶段静默挂起、会话模型设置不生效等问题。\n- 安全与清理：修复 JEV 模式下 Code Mode 误判批准，移除旧版 workspace ZIP 接口。\n- 稳定线维持 v2.2.2.post1，2.3.0 仍在 beta 通道。\n\n## OpenClaw（开源）\n- 11-03 发布 **openclaw 2026.10.10 正式版**，结束 10.10-beta.5 预发布周期；发布说明与 changelog 双格式输出（人类可读版 + 面向
