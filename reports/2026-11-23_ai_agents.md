# AI Agent 赛道日报 2026-11-23

## 摘要
今日开源 Agent 框架侧更新密集：OpenClaw 推送 2026.11.10-beta.2，重点在更新中断后自恢复、子 Agent 已完成结果的持久化投递与首轮对话时延压缩；QwenPaw 发布 v2.3.1-beta.1，将 MCP、本地模型管理、本地 Whisper 全面插件化，并加严高危操作审批。产品侧 WorkBuddy 无新版本，社区出现 Obsidian 知识库联动与 HY3 免费额度实操；行业侧出现办公 Agent 规模化与 FDE 交付模式的观察长文。

## 重大信号
- [OpenClaw] 2026.11.10-beta.2 发布：更新恢复机制、后台子 Agent 结果持久化、Webhook 1MiB 与插件侧问题分叉会话 — https://github.com/openclaw/openclaw/releases
- [QwenPaw] v2.3.1-beta.1 发布：MCP / 本地模型管理 / 本地 Whisper 插件化，shell 发邮件与 HTTP 写入需审批 — https://github.com/agentscope-ai/QwenPaw/releases

## 阿里 QwenPaw
- 11-23 发布 v2.3.1-beta.1（Pre-release），核心是能力边界全面插件化：MCP 抽离为插件、本地模型管理抽离为插件、本地 Whisper 转为 SDK 插件并由框架托管生命周期 — https://github.com/agentscope-ai/QwenPaw/releases
- 安全侧加严：基于 shell 的邮件发送、HTTP 写操作与文件上传改为需人工审批；同时修复卷根目录写入沙箱 ACE 的问题 — https://github.com/agentscope-ai/QwenPaw/releases
- 渠道侧新增 QQ C2C 流式消息、QQ 群全量消息与仅 @ 过滤、小艺可选流式与传输加固、钉钉 AI 卡片 Markdown 表格与正文分段修复 — https://github.com/agentscope-ai/QwenPaw/releases
- 客户端与控制台：外部发起的会话可在控制台重连、响应式输入区控件稳定、标签页 favicon 仅显示未读完成；读取工具改为 GBK/CP936 解码，Ollama 按 num_ctx 设置上下文窗口 — https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw（开源）
- 11-23 发布 openclaw 2026.11.10-beta.2（Pre-release），主要方向为可靠性：包替换中断后保持可运行、崩溃或重启后下次更新可安全完成 — https://github.com/openclaw/openclaw/releases
- 后台任务链路加强：已完成子 Agent 结果在 Gateway 重启、父轮次中断、兄弟任务活跃时仍保留并恢复投递；sessions_send 不再阻塞超时 — https://github.com/openclaw/openclaw/releases
- 首轮体验优化：模型目录加载期间即可接受首条消息，长历史压缩不再全量驻留 Gateway 内存 — https://github.com/openclaw/openclaw/releases
- 新增插件侧问题分叉：插件可基于会话实时上下文派生后台任务，带自有工具与策略控制的文件/命令权限；Webhook 支持 1MiB 请求体与批量 Gmail 通知扇出 — https://github.com/openclaw/openclaw/releases
- 渠道修复覆盖 Telegram、Discord、WhatsApp、Matrix、Slack，以及 Twilio MMS 图片、飞书长流式回复与会议音视频保活 — https://github.com/openclaw/openclaw/releases
- releases 导航中稳定版标签已更新至 openclaw 2026.11.7（此前为 2026.11.6） — https://github.com/openclaw/openclaw/releases
