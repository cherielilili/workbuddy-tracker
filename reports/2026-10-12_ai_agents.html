OpenClaw（开源）

  • 2026.10.2 稳定版发布，为 10.1 之后的稳定迭代；同日推出 2026.10.5-beta.2 预发布版。
  • 2026.10.5-beta.2 要点：升级流程可清理过期 handoff 租约、完成回执与旧版恢复记录，不再将成功更新误报为失败；Doctor 工具在路径安全拦截时保留插件配置，迁移前备份 Canvas 与 Memory Core 数据。
  • 安全加固：经信任内联审批的工具参数不可再被 hook 改写，转换参数的插件须对最终参数重新申请审批；子 Agent 消息来源标记贯穿会话重放，防止父级指令被误呈为用户指令；Tool Search 与 Code Mode 的网络结果与直接网络调用同等标记污染。
  • 其他：兼容低于 2026.9.7 的官方 Codex 运行时将被插件准入拒绝并给出修复指引；大量会话创建合并为单条摘要通知；更新性能优化，不再重复哈希未变化的运行时文件。
