# AI Agent 赛道日报 2026-10-27

## 摘要
腾讯 WorkBuddy 发布 5.9.3 补丁版本，集中修复跨设备迁移粒度、Windows 升级链路与会话模型回退问题；阿里 QwenPaw 推出 v2.3.0-beta.1，引入 Advisor Mode、实验性 Python Code Mode、桌面共享守护进程与决策模型驱动的工具审批；OpenClaw 迭代 2026.10.10-beta.4，强化网关令牌隔离、记忆 Wiki 人工注释保留与 CLI 配置写入链路。Stanford HAI 活动日历新增多场 10 月末至 12 月的讲座与研讨会排期。

## 重大信号
- **[Alibaba / QwenPaw]** QwenPaw 发布 v2.3.0-beta.1（10-27），为 2.3 系列首个功能版预发布：新增 Advisor Mode、插件 inline OpenUI 支持、Firecrawl 检索源、决策模型驱动的工具审批模式、桌面共享守护进程与实验性 Python Code Mode，记忆层集成 ReMe 0.4.2.0。来源：https://github.com/agentscope-ai/QwenPaw/releases

## 腾讯 WorkBuddy
- 更新日志上线 5.9.3（2026-10-27），延续 5.9.x 的稳定性修复节奏，本版无新增功能：跨设备数据迁移支持按分类选择，导入上限提升至 100GB；修复 Windows 因安装目录校验导致的升级检查失败，以及静默升级后新进程未继承完整环境变量、sandbox 初始化失败引发全部工具报错的问题；修复重启后历史会话所用模型被误回退、长会话打开时段崩溃等体验缺陷。https://www.codebuddy.cn/docs/workbuddy/Changelog

## 阿里 QwenPaw
- v2.3.0-beta.1 预发布（2026-10-27）要点：新增 Advisor Mode；插件支持 inline OpenUI（Intelligent UI）并引入 clean unload 与回滚安全热重载；web_search 增加 Firecrawl provider，Tavily 支持凭据存储的可选 API key；新增 TypeSafe 决策模型配置，并基于决策模型实现工具审批模式（安全侧）；桌面端改为共享守护进程，支持独立窗口与协同更新；实验性 Python Code Mode；记忆层集成 ReMe 0.4.2.0，支持可选决策压缩、图像与标签；ACP 增加 --agent-mode；支持本地 ChatGPT 订阅登录；creator 2.0.3 上线技能、旁白、草稿与脚本导入。工程侧替换 GPL 许可的 html2text 为标准库实现，前端新增 106 个单测文件。https://github.com/agentscope-ai/QwenPaw/releases

## Open Source / OpenClaw
- 预发布 2026.10.10-beta.4（10-27）主要修复：Automations 在同会话显式定时跟进中保留已认证操作者权限，同时维持角色、会话、取消与工具策略的回收边界；Gateway 安全侧确保被环境变量引用的 hooks.token 不进入 agent host-exec 与 CLI 子环境；Memory Wiki 在 OKF 概念页重导入/移除时保留人工撰写的 Notes；Claude CLI 在 Control UI 启动会话中保持原生上下文不被历史重置；备份恢复保留合法的 exec-approval 允许列表而非替换为全拒；macOS 捆绑 Gateway 正确显示实际安装版本并修复受阻的恢复流程；CLI 的 config set/unset 与 setup 改为经运行中 Gateway 以 config.patch 一次性提交，无需重启；Codex 原生子代理在完成、中断与 Gateway 重启场景下正确解阻父会话并重放孙任务；同时回补修补后的内嵌运行时。https://github.com/openclaw/openclaw/releases
