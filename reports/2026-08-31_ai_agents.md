## 开源 / OpenClaw
- **OpenClaw 2026.8.1 稳定版发布（08-31）**，取代 2026.7.1-2 成为最新稳定版，亮点包括：
  - 会话全文检索：按关键词搜索历史对话并定位上下文
  - 跨 Gateway 会话：可在配对设备或云端 Worker 上运行任务，工作区随会话迁移，复用预热机器
  - 持久化进度卡片：跨刷新跟踪子 Agent 活动与累积编辑
  - 结构化问答：通过 Web/原生卡片、消息按钮回答 Agent 提问，支持自由文本与显式跳过
  - 交互式组件与仪表盘：聊天内 widget 可固定到会话仪表盘并导出图片
  - 私密凭据请求：Agent 通过掩码提示索取凭据，不进入聊天与模型上下文，支持代理限定密钥注入目标
  - 自动化权限一次审批：对精确操作授予权限，可后续查看/撤销，任务变更需重新审批
  - 音视频增强：媒体跨上传与刷新保持挂载，Apple/Android 客户端支持原生播放与视频上传
  - **破坏性变更**：移除内置 OpenProse 插件及 /prose 命令（迁移至上游 Agent Skill）；OpenAI 路由迁移，codex/* 与 openai-codex/* 模型引用统一迁移至 openai/*（通过 openclaw doctor --fix 执行）
  - 2026-09-01 起 plugin-sdk 多个子路径将移除，外部插件需提前迁移
  - 官方 Provider 包拆分：BytePlus、ComfyUI、Mistral、NovitaAI、OpenCode、Volcengine、小米等改为按需安装

## 阿里 QwenPaw
- **v2.2.0-beta.5 预发布（08-31）**：渠道契约检查可移植化补全；记忆 embedding 重建索引改为显式且限定范围；版本号升至 2.2.0b5。
- **v2.2.0-beta.4 预发布（08-31）**：限制超长单行工具结果；桌面端统一打包 Python 运行时来源；修复元宝 protobuf 6+ 解码；插件加载后不再全量扫描模块；CI 跳过草稿 PR。
