{"report_md": "# AI Agent 赛道日报 2026-10-15\n\n## 摘要\n开源 Agent 框架成为今日主要变量：阿里 QwenPaw 将 v2.2.2 从 beta 转为正式版，落地 Hub 模型网关、内置终端与 PawPort 迁移工具；OpenClaw 推出 2026.10.10-beta.1，重点重构 Gateway 性能、云端会话与桌面端本地 Gateway，并将 Gemini 4 Argon 设为默认 Gemini 模型。Stanford HAI 新增多场公开讲座、研讨班与学生会议排期。\n\n## 重大信号\n- **[Alibaba / QwenPaw]** v2.2.2 正式版发布（2026-10-15）：把 beta 期能力转为稳定版，新增 Hub 模型网关与成员 token 预算、PawPort 跨工具导入（Codex / Qoder）、Chat 内置多标签终端、六套主题调色板，QwenPaw-Flash 新增 27B 与 35B-A3B 本地推荐，QwenPaw Data 升级至 0.3.0。详见 https://github.com/agentscope-ai/QwenPaw/releases\n- **[Open Source / OpenClaw]** 2026.10.10-beta.1 预发布（2026-10-15）：Gateway 大幅降低 SQLite 与主线程开销，更新流程与重启后的回复恢复更可靠，支持本地与云端会话互迁、桌面应用运行本地 Gateway，并引入 Gemini 4 Argon、Gemini 3.8 Flash、Nemotron 3.5 Super VL、xAI Imagine Image 2.0 与 Muse Code 承载的 Meta 模型；平台最低要求提升至 macOS / iOS / Safari 26.2。详见 https://github.com/openclaw/openclaw/releases\n\n## 阿里 QwenPaw\n- 发布 **v2.2.2 正式版**（10-15），此前 beta 能力全部转正：\n  - Console 与工作区：新增六套主题调色板与自定义颜色、圆角，支持实时预览与偏好保存；Chat 内新增带鉴权的多标签终端，每个会话独立工作目录；Console 字号可在 12–20 像素间调节；多文件夹工作区可保存为 Agent 默认；Agent 交付文件直接展示在回复下方。\n  - QwenPaw-Flash：本地模型推荐更新为 9B、27B、35B-A3B 三档。\n  - PawPort：可从 Codex 与 Qoder 导入会话、记忆、Skills、插件、MCP 设置、项目与定时任务，具备兼容性检查与选择性重试。\n  - Creator 升级至 2.0.1：媒体生产前可审阅脚本，手动重新生成不触发付费下游步骤，可恢复停滞项目。\n  - QwenPaw Data 升级至 0.3.0：集成分析工作区、交互式澄清、内联 HTML 报告，聊天频道支持 /data 与 /datasource 指令。\n- 模型与记忆：统一模型发现、定价与选择，提供候选模型池及按会话的模型与思考控制；自定义 provider 的名称、端点、协议与 API Key 可在一个对话框配置；ReMe 搜索重排可配置；记忆命令统一为 /reme <action> key=value。\n- Hub 模型网关：集中管理组织模型、成员 token 预算、用量看板与邀请注册，支持命令行初始化首个 Hub 管理员（含无 Docker SDK 的纯本地部署）。\n- 工具、自动化与渠道：新增 view_audio 工具复用既有转写管线；定时任务支持纯文本指令与模型选择，中断后保留历史；Skill 可批量分发到工作区并分配给自定义渠道；Skill Market 源（QwenPaw / ClawHub / ModelScope / Aliyun）以插件方式装卸；飞书支持可折叠思考面板，Telegram 回复中的 Markdown 表格渲染为原生 Rich Messages。\n- 体验与性能：长会话减少重复历史库校验，会话列表默认按来源分组，聊天依赖与语言资源按需加载以降低初始下载。\n- 来源：https://github.com/agentscope-ai/QwenPaw/releases\n\n## OpenClaw\n- 发布 **2026.10.10-beta.1**（10-15）：\n  -
