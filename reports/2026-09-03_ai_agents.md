# AI Agent 赛道日报 2026-09-03

## 摘要
今日赛道迎来密集更新：腾讯 WorkBuddy 在两周内连续发布 v5.4.0 至 v5.5.2 多个版本，v5.5.0 引入行业 Buddy 应用与图片处理能力；阿里 QwenPaw 发布 v2.2.0 稳定版，新增自托管 Hub、邮件助手与数据分析应用；开源 OpenClaw 发布 2026.9.1，强化图表渲染、安装引导与升级回滚机制。Stanford HAI 新增多场秋季研讨班，包括 11 月 AI 100 第三期报告解读讲座。

## 重大信号

- **[Tencent] WorkBuddy 连发 v5.4.0–v5.5.2 多版本**：v5.5.0 新增行业 Buddy 应用（专属首页/专家/技能/连接器）、图片处理（去水印、修复、抠图）与系统级微信聊天记录转发；v5.4.0 支持 Worktree 并行开发任务。https://www.codebuddy.cn/docs/workbuddy/Changelog
- **[Alibaba] QwenPaw v2.2.0 稳定版发布**：新增可自托管多用户 QwenPaw Hub、QwenPaw Data 数据分析应用、QwenPaw Mail 智能邮件助手，统一模型供应商发现与能力路由，扩展 Token 用量观测。https://github.com/agentscope-ai/QwenPaw/releases
- **[OpenClaw] OpenClaw 2026.9.1 发布**：Mermaid 图表全端渲染、一键快速安装引导（自动检测 Claude Code/Codex 凭据）、共享 Gateway 个人技能库、升级失败自动回滚与 Gateway 高可用修复。https://github.com/openclaw/openclaw/releases
- **[Stanford HAI] 新增 11-18 Mike Wooldridge《The AI 100》研讨班**：将解读 2026 年 10 月发布的 AI 100 第三期报告核心洞见。https://hai.stanford.edu/events

## 腾讯 WorkBuddy

- **v5.5.2（09-03）**：优化积分到期提醒与明细分类展示；恢复 Ctrl/Cmd+Enter 换行习惯；修复会话报错消息消失、自动化任务误判补跑、美团助手微信支付确认未展示等问题。https://www.codebuddy.cn/docs/workbuddy/Changelog
- **v5.5.1（09-02）**：视频生成支持画面比例、声音与负向描述；侧栏显示客户端版本号；提升云助理建连与任务切换速度；优化订阅用量页与敏感内容确认流程。
- **v5.5.0（09-01）**：新增行业 Buddy 应用，按场景提供专属首页、专家、技能和连接器；支持 macOS/Windows 系统分享入口将微信聊天记录发送至 WorkBuddy；新增图片去文字/水印、修复、增强、美颜、透明背景抠图；增强腾讯文档读写操作场景。
- **v5.4.7（09-01）**：新增订阅和用量设置页，应用内购买积分、管理自动续费；修复三档模型无法发送图片等问题。
- **v5.4.0–v5.4.5（08-20 至 08-30）**：v5.4.0 支持 Worktree 任务并行开发、Git 分支安全切换、独立终端面板、3D 模型生成与本地 PPT AI 编辑撤销重做；v5.4.5 新增记忆与进化快捷入口、模型档位按会话记忆；其间多版本修复专家启动、连接器授权、超长会话加载等问题。

## 阿里 QwenPaw

- **v2.2.0 稳定版（09-03）**：自 v2.2.0-beta.7 转正式版。核心新增：QwenPaw Hub 多用户自托管（本地进程或 Docker 运行时、工作区级访问控制、凭证管理）；QwenPaw Data 原生 PawApp 数据分析工作区；QwenPaw Mail 智能邮件助手（实时监控、线程感知操作、发件人白/黑名单、未知收件人人工审批）；统一模型供应商发现与能力路由，新增火山引擎 Agent Plan 与 MiMo V2.5；Creator 1.1.x 扩展图像/视频生成；Console 子代理会话分组、Token 用量多维观测、技能与应用统一市场（Marketplace 更名 Extensions）。https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw

- **2026.9.1（09-03）**：Mermaid 代码块在 Control UI 及 macOS/iOS/Android 原生端渲染为图表；全新安装提供快速通道，自动检测并验证已有 Claude Code/Codex 登录与 API Key；共享 Gateway 支持个人技能库（ZIP 导入、按身份共享发布）；openclaw update 升级失败自动回滚并保留配置与密钥引用；Gateway 在负载与大型 agent  roster 下启动恢复、异常 cron 行隔离启动；Codex MCP 工具 Allow Always 持久化；审批卡片回传至来源聊天渠道（含 Telegram topics）；Android 端聊天与设置对齐 Web UI。https://github.com/openclaw/openclaw/releases
