# AI Agent 赛道日报 2026-10-23

## 摘要
腾讯 WorkBuddy 灰度推送 5.9.0，新增独立文件浏览器新窗口打开、自定义模型入口与海外版消息中心，并同步发布 5.8.3 稳定性修复；OpenClaw 正式发布 2026.10.6 稳定版，强制要求修补后的 Node 运行时并大幅强化升级回滚与迁移备份可靠性；阿里 QwenPaw 推送 v2.2.2.post1 安全修复版；Stanford HAI 上线劳动力市场 AI 影响的实时追踪看板。

## 重大信号
- **[Tencent]** WorkBuddy 5.9.0 灰度发布：新增独立文件浏览器 HTML 新窗口打开、模型选择器自定义模型入口、购买成功后 Buddy One 绑定引导、海外版消息中心及运营位；同时修复连接器 Token 失效无修复入口、专家团任务中断及成员丢失等问题。来源：https://www.codebuddy.cn/docs/workbuddy/Changelog
- **[OpenClaw]** 2026.10.6 稳定版发布：强制要求 Node 24.22.1+（24 线）或 26.12.1+（26 线）以拒绝被入侵证书签发的 TLS 链，Docker 镜像与安装器同步切换；升级流程在旧 Node 上会拒绝安装并给出恢复指引，同时强化包切换安全性、迁移备份的数据保全与跨重启投递可靠性。来源：https://github.com/openclaw/openclaw/releases

## 腾讯 WorkBuddy
- 5.9.0（2026-10-20，灰度中）为本次主更新：独立文件浏览器支持 HTML 在新窗口打开；新增模型选择器中的自定义模型配置入口；新增购买成功后 Buddy One 绑定引导；新增海外版消息中心与运营位。优化技能分享落地页与弹窗、浏览器操作工具标题展示、连接器失败与模型繁忙提示、Buddy 应用窗场景模板避免覆盖已输入内容、AI native 助理右侧栏加载速度。修复特殊字符路径与 Office 宏格式文件无法打开、连接器 Token 失效无修复入口、无效 Key 误报已连接、频道 IM 删除消息卡片一直显示同步中、资料库按文档类型筛选不显示 docx、频道资料库导出白屏、专家搜索优先级错误、专家团任务中断及成员丢失等问题。来源：https://www.codebuddy.cn/docs/workbuddy/Changelog
- 5.8.3（2026-10-19）：修复内置运行时随版本切换弹出闪屏、账号刷新串号导致会话错乱、企微助理会话结束后入口默认回到本地助理、语音功能被异常覆盖不可用；优化本地沙箱内存占用（修复长期运行内存膨胀卡死）与企业代理/系统证书环境下的连接稳定性。来源：https://www.codebuddy.cn/docs/workbuddy/Changelog

## 阿里 QwenPaw
- v2.2.2.post1（10-22）为安全修复补丁：修复 emSign CA 信任链在依赖、安装器与构建产物中的问题，并将 Node.js 升级至 22.23.4。功能面沿用 10-15 的 v2.2.2（Console 六套主题、多标签终端、PawPort 迁移、Hub 模型网关、view_audio、Flash 27B/35B-A3B、Creator 2.0.1）。来源：https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw
- 2026.10.6 稳定版（10-22）：本次为纯可靠性补丁，不引入新面向用户功能。核心为运行时安全基线（Node 24.22.1+/26.12.1+，源码构建锁定 pnpm 12.15.0）、更安全的升级与恢复（拒绝不安全服务状态、Windows/macOS 包管理器更新可从平台特定故障中恢复）、数据保全式迁移与备份（拒绝畸形或有损的工作区导入、保留畸形 Notes 字节、拒绝非 UTF-8 wiki 重写、保留深层嵌套 SQLite 备份）、跨重启可靠投递（队列轮次、子结果监听、死信投递与流式回复不丢失不重复）、供应商与模型韧性（GPT-5.6 工具轮次、OpenRouter DeepSeek 工具调用、LM Studio 溢出恢复、并行推理设置、重试/回退预算）、Windows 与移动端稳定性，以及 Agent 工具调用恢复与各渠道（WhatsApp/Telegram/Slack/Discord）投递正确性修复。来源：https://github.com/openclaw/openclaw/releases
