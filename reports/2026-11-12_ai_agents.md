## OpenClaw
- 发布预发布版本 2026.11.5-beta.2（2026-11-12 00:43），稳定版仍为 2026.11.3。核心变化为超长会话可双向分页浏览历史、显示历史边界，并对归档读取做有界限制，缓解大上下文会话的加载阻塞（#188450、#188483、#190690）。
- 可靠性修复：消息投递对已提交输入的重试不再产生重复轮次，内联编辑期间保留排队消息；会话快照补全、压缩过程中保留活跃请求来源，中断后可恢复配置的 fallback 模型。
- 安全与认证加固：使用 fast-uri 4.2.3 拒绝畸形 URI 标识符；Discord SDK 提前拒绝超大有界集合；Anthropic setup-token 凭据与 API-key 配置分离；macOS 应用在配置保存失败或关闭 Tailscale 暴露时保留已保存密钥与 Gateway 认证。
- 平台层调整：Gemini Flash 在官方端点改用 Interactions API 并保留自定义端点覆盖；Android 结束 Talk 不再取消 Gateway 已接受的工作；Matrix 新线程会话不再复制房间记录；PostgreSQL 会话搜索稳定走文本索引。
