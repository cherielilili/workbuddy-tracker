# AI Agent 赛道日报 2026-08-24

## 摘要
今日赛道动态集中在开源 Agent 框架侧：阿里 QwenPaw 发布 v2.1.1-beta.2 预发布，引入自托管多用户 Hub 与技能自动更新；OpenClaw 发布 2026.8.1-beta.3 预发布，扩展 GPT-5.6 全系推理模型支持并强化网关生命周期管理。商业产品侧今日无新版本或官方公告。

## 阿里 QwenPaw
- **v2.1.1-beta.2 预发布（08-24）**：新增自托管多用户 Hub（支持本地与 Docker 运行时）；内置技能自动更新；Console 助手回复卡片支持 artifacts 展示；token 用量按 Agent 归因；会话级多项目目录；Creator 升级至 1.1.0（主流图像/视频供应商、Anthropic/Gemini 协议、2GB 上传等）；修复长会话响应性能与长思考累积的二次方开销问题。来源：https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw（开源）
- **2026.8.1-beta.3 预发布（08-24）**：GPT-5.6 Sol、Terra、Luna、Ultra 推理支持覆盖 OpenClaw 与 Codex 运行时；Control UI 首次启动引导接入 Custodian 验证模型配置与渠道设置；新增 Puppeteer 兼容 CDP relay 支持配对 Chrome 会话；外部 Gateway 生命周期显式监管与验证重启交接；新增紧凑可验证的 SQLite 备份与新目标恢复命令；渠道插件共享持久化 ingress 监控；89 个官方 npm 插件完成完整性回读校验。来源：https://github.com/openclaw/openclaw/releases
