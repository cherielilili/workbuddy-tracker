## OpenClaw（开源）

- 发布预发布版 2026.10.10-beta.5（10-30），稳定版仍为 2026.10.9。来源：https://github.com/openclaw/openclaw/releases
- Node 兼容性恢复：安装与更新重新支持 Node >=24.16.0 <25 与 >=26.1.0；Node 24.22.1 / 26.12.1 从硬性要求降为安全建议；Node 26 worker 在 stdin 为文件时不再中止（#186589、#187516）。
- 网关流式回复修复：包含类工具调用 XML、疑似工具调用、或在部分标签处截断长 HTML 的回复不再卡住 Gateway（#181397、#183252、#180765）。
- 更新与回滚可靠性：npm 回滚失败不再让已安装包陷入异常；即时 Git 回滚保留运维改动；执行器中断的更新可恢复其离线状态。
- 定时任务：存储的下次运行时间已过期的错过时段不再被丢弃；重启后的启动补偿运行可正常进入队列。
- 安全边界收紧：exec 允许列表模式下 test / [ -v 操作数需审批；拒绝经通用 node invoke 下发的浏览器代理命令；沙箱派生子进程解析 CLI 模型时 fail closed；将 workspaceOnly 传递到 Gateway 构建的代理与媒体工具；Microsoft Teams 允许列表保持限制性并阻止构造 HTML 在发件人校验前拖住 Gateway；拒绝 Android 固定网关连接上的嵌入式 Control UI 认证；审计符号链接形式的工作区技能根目录。
- 凭据保护：浏览器配对凭据不再出现在 opener 进程参数中；日志掩码 Google OAuth client secret；MCP CLI 检查与搜索端点错误信息中去除凭据。
- 依赖安全：升级 fast-uri，限制 A2UI 与 Discord 输入中 vendored Zod 的遍历边界，Microsoft Teams 改用修补版 MSAL，IMAP 采用 nodemailer 发件人解析修复。
- 终端输出加固：camera、channel capability、DNS setup、managed worktree、plugin uninstall、skills library、Gateway discovery、MCP registry、model auth profile、session store、storage location 等 CLI 输出统一转义控制序列。
- 会话与回复：空闲重置保留 transcript ID，/new、/reset 后保留关联模型账号，已清除历史不进入 fork；多行 /btw、/loop、/acp 输入不再被截断。
