# AI Agent 赛道日报 2026-11-11

## 摘要
今日 QwenPaw 结束 2.3.x 公测、正式发布稳定版 v2.3.0，一次性补齐本地决策模型、Advisor/Python Code 双模式、记忆体系升级与双语评测页，是本轮更新中体量最大的产品级变动。Stanford HAI 方面新增一条神经科学与 AI 交叉研究的资助类新闻，活动日历则延伸至 2027 年的 PhyStat 会议。其余主流 Agent 产品线今日无版本或文档增量。

## 重大信号
- **[Alibaba / QwenPaw]** v2.3.0 正式版发布（由 beta.4 转正），核心增量：Piccolo 4B/9B/27B 本地决策模型用于工具审查与上下文压缩、Advisor Mode（顾问模型 + 执行模型双模协作）、实验性 Python Code Mode、ReMe 0.4.2.0 图像记忆与自动标签、支持以 ChatGPT 订阅登录本地安装、Firecrawl/Tavily 检索接入、AnySearch 成为默认搜索、双语评测页。来源：https://github.com/agentscope-ai/QwenPaw/releases

## 阿里 QwenPaw
- v2.3.0 稳定版发布（11-11），此前为 v2.3.0-beta.4 预发布；本次为功能级大版本，非补丁更新。https://github.com/agentscope-ai/QwenPaw/releases
- 本地决策模型：新增 Piccolo 4B / 9B / 27B，用于工具调用审查与上下文压缩，提供 BF16 与 Q8_0 推荐配置，支持运行时安装更新及 Hugging Face / ModelScope 下载；审查与压缩仍为可选项，本地运行时同时只服务一个模型。
- Agent 模式：新增 Advisor Mode，顾问模型与执行模型配对，先出开篇计划、按需咨询顾问，并在工具反复失败后调整计划；新增实验性 Python Code Mode，可在一个脚本内组合已启用工具、并发调用并保序输出文本与媒体（原生工具权限仍生效，不开启沙箱）。
- 记忆体系：ReMe 升级至 0.4.2.0，支持图像记忆、自动标签、标签筛选检索与决策模型上下文压缩（保留原始工具输出引用）；ReMe Light 记忆文件支持标签页浏览；新增 OpenViking 记忆插件，支持自动召回与已完结轮次持久化。
- 模型与审批：本地安装可使用 ChatGPT 订阅登录并选择账号可用模型（无需 Platform API Key）；TypeSafe/JEV 决策模型可与聊天模型分开配置并用于工具审批，显式拒绝仍强制生效，不确定或服务失败转人工审批。
- 检索与渠道：新增 Firecrawl 作为网页检索 provider、Tavily 支持可选 API Key 与无 Key 降级；AnySearch 成为未保存 provider 时的默认检索；Matrix 渠道随安装带入端到端加密依赖。
- 控制台与桌面：新增可选 OpenUI 插件在回复内渲染交互表单并保持流式状态；Inbox 增加仅看未读筛选；桌面多窗口共享后台服务，关闭最后一个窗口后任务继续；审批、回复完成与后台任务支持浏览器/桌面通知并可点击跳回会话。
- 其他：QwenPaw Community 支持控制台内浏览、排序与评论并同步至收件箱；Creator 升级 2.0.4，Data 升级 1.0.3；新增双语评测页，提供基准分数、成本与运行时对比、可调权重、版本历史与结果下载。
