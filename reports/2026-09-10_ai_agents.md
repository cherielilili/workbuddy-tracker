# AI Agent 赛道日报 2026-09-10

## 摘要
今日新增动态集中于开源 Agent 运行时：阿里 QwenPaw 推送 v2.2.1-beta.2 预发布，围绕技能依赖校验、MCP 超时配置与记忆后端插件化做增量优化；OpenClaw 发布六月扩展稳定线收官版 2026.6.35，集中回补安全边界与长任务投递可靠性。国内商用办公智能体与学术研究侧今日未见新增。

## 重大信号
- [OpenClaw] 六月扩展稳定线（LTS）收官版 2026.6.35 发布：对内置 provider 与渠道适配层统一收口不可信响应体与超大输入，修复长任务取消、重试、部分投递与进程流失败导致的丢活问题，并加固本地工具、浏览器自动化与工作区读取的输入校验。该版本为这条 LTS 分支的最后一次发布，仅含经审计的安全与可靠性回补，不引入新功能线特性。https://github.com/openclaw/openclaw/releases

## 阿里 QwenPaw
- v2.2.1-beta.2 预发布（2026-09-10）：控制台移动端 Agent 选择器优化，应用更新提示可识别版本不匹配场景。
- 技能（Skills）能力升级：技能版本对外暴露，并支持校验其声明的依赖，配套更新技能市场 clawhub 链接。
- MCP 客户端支持为 HTTP/SSE 连接配置超时，缓解长耗时工具调用被提前中断。
- 记忆后端重构：ADBPG 与 PowerContext 迁移为插件形态，插件后端不可用时自动回退，统一自动记忆生命周期。
- 稳定性修复：排队发送与切换会话时的会话竞态、备份恢复时保留 SECRET_DIR 与 .master_key 的 Unix 权限位、出站媒体支持 Base64 data URL、工作区外文件上传展示收敛。
- 来源：https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw
- 2026.6.35 发布（2026-09-10）：六月扩展稳定线（LTS）的收官版本，定位为经审计的安全与可靠性回补集合。
- 边界与输入安全：内置 provider 与渠道适配器对不可信响应体设置读取上限，在昂贵操作前拒绝超大输入，传输失败时保留安全恢复路径。
- 长任务投递可靠性：agent、gateway、重试与渠道链路在取消、重试、部分发送及进程流失败场景下不再丢失工作或重放不安全操作。
- 内置插件韧性：本地模型、浏览器、媒体与协作插件可从畸形载荷、超时与上游瞬时故障中干净恢复。
- 工具与工作区安全：浏览器自动化、本地工具、工作区读取与插件元数据处理在解析前拒绝畸形或超大输入，避免中断进行中的 Agent 运行。
- 内存安全修复：provider、搜索、嵌入、媒体与渠道集成的成功与错误响应读取均加上限，防止恶意载荷耗尽进程内存。
- 来源：https://github.com/openclaw/openclaw/releases
