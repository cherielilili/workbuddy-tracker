## OpenClaw
- 2026.8.1-beta.2 预发布（08-15）：密钥出口主机绑定（Secret egress host binding），可将共享存储密钥绑定到指定 HTTPS 目标主机，未绑定的哨兵替换在明文外发前即失败关闭，覆盖 CLI、Gateway RPC 与 Control UI；支持 GPT-5.6 Ultra（Sol/Terra/Luna）并在 OpenClaw 与 Codex 引擎间运行时切换；新增渠道插件入口监控共享 SDK（IRC、Synology Chat、Google Chat 迁移至统一生命周期）；新增 SQLite 快照备份命令 openclaw backup sqlite；macOS 应用配置隔离（多实例独立状态、偏好与 Keychain）；插件安装来源告警（任意可执行插件源需 --force 显式确认）；Control UI 更新恢复体验修复。来源：https://github.com/openclaw/openclaw/releases
- PR #124528 Gateway profile evidence 预发布（08-16）：发布三节点、十二并发 Gateway 测试平台的 CPU profile 存档，用于 PR #124528 事件循环热点对比，属性能验证材料。来源：https://github.com/openclaw/openclaw/releases
