# AI Agent 赛道日报 2026-11-09

## 摘要
今日可读源中仅阿里 QwenPaw 出现新动作：开源版放出 v2.3.0-beta.3，把 AnySearch 设为默认联网搜索提供方，并首次将本地小模型 Piccolo 做成可安装运行时。其余厂商的官方更新日志与社区页面在过去 24 小时内没有新增条目。

## 重大信号
- **[Alibaba / QwenPaw]** v2.3.0-beta.3 预发布（2026-11-09）：默认联网搜索切换为 AnySearch，新增 OpenViking 记忆插件，本地 Piccolo 模型运行时开始支持安装与模型源选择，桌面端增加审批通知。来源：https://github.com/agentscope-ai/QwenPaw/releases

## 阿里 QwenPaw
- 发布 v2.3.0-beta.3（2026-11-09 11:44，预发布），承接 beta.2 的 channels 插件化改造，本轮以能力接线与稳定性修复为主：https://github.com/agentscope-ai/QwenPaw/releases
- 搜索能力变更：web_search 默认提供方改为 AnySearch，并补充了内置搜索提供方的文档说明，属于对默认工具链的实质性替换。
- 本地模型闭环推进：新增长期记忆插件 OpenViking（含前端 lockfile）；Piccolo 本地模型支持运行时安装、模型源选择与双向候选打分，本地侧推理能力继续下沉。
- 桌面与协作端：新增审批通知；Matrix 默认安装 E2EE 依赖并修复 Windows 下 crypto store 命名与旧状态迁移；钉钉长回复按 markdown 分片，避免超长消息被截断。
- 社区与插件生态：集成 QwenPaw community 与 inbox；Console 侧持久化市场安装来源，使 Update All 覆盖第三方插件，并重构插件依赖检查与 Windows 依赖升级流程。
- 稳定性与安全：shell 增加可选的记忆保护并可在 Console 实时配置；上下文摘要兼容慢速模型与统一 token 限制；SSE 关闭 nginx 缓冲；修复 CRLF 行尾被改写、上下文溢出恢复、渠道泄漏自动记忆召回载荷等问题。
