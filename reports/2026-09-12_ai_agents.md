# AI Agent 赛道日报 2026-09-12

## 摘要
今日赛道动态集中于桌面端与开源 Agent 的产品版本迭代：腾讯 WorkBuddy 连发 5.5.5、5.5.6 两个版本，新增创意设计（图片/视频生成）能力并改进自动化任务重试逻辑；阿里 QwenPaw 发布 v2.2.1 稳定版，引入按 Agent 独立的模型路由与长期记忆新后端；OpenClaw 发布 2026.9.4，上线统一插件工作区与预备云会话能力。

## 重大信号
- **[Tencent / WorkBuddy]** 发布 5.5.5 与 5.5.6（2026-09-10）：新增创意设计能力，覆盖图片生成、视频生成与品牌设计场景；发起任务时可直接添加资料库文档或空间作为参考；后台任务支持查看详情与终端输出并可随时取消；企微转发的聊天记录可自动读取文档、微盘、日程、待办、会议与智能纪要。来源：https://www.codebuddy.cn/docs/workbuddy/Changelog
- **[Alibaba / QwenPaw]** v2.2.1 正式版发布（2026-09-11）：支持为每个 Agent 单独配置模型路由（含 provider 偏好与 fallback）；新增 Auto Fin 主动记忆复盘，PowerContext 成为可选长期记忆后端；QwenPaw Creator 升级至 1.2.0，加入蓝图工作台、多时间线对比与项目快照回滚。来源：https://github.com/agentscope-ai/QwenPaw/releases
- **[OpenClaw]** 发布 2026.9.4（2026-09-11）：统一插件工作区，可在 Control UI 中安装并管理内置与 ClawHub 插件；支持从本地项目或公开 GitHub 仓库启动预备云会话并复用快照；兼容失败的更新可在校验通过后回滚至旧包与旧配置；新增终端内交互式问答与 GPT Image 2.5 变体。来源：https://github.com/openclaw/openclaw/releases

## 腾讯 WorkBuddy
- 5.5.6（09-10）：优化自动化任务重试，失败后可在当前会话继续，避免创建重复任务会话；修复重试成功后运行历史状态不准确、切换任务后旧错误再次出现的问题；优化错误提示，不再展示内部错误码；提升插件推荐的主动性与准确度 https://www.codebuddy.cn/docs/workbuddy/Changelog
- 5.5.5（09-10）：新增创意设计能力，支持图片生成、视频生成和品牌设计场景；发起任务时可直接添加资料库中的文档或空间作为参考内容；后台任务支持查看详情与终端输出，并可随时取消运行；「数据管理—应用」支持直接发布或取消发布应用 https://www.codebuddy.cn/docs/workbuddy/Changelog
- 5.5.5（09-10）：从企业微信转发聊天记录后，可自动读取其中的文档、微盘文件、日程、待办、会议和智能纪要；优化复杂 Mermaid 图表 Markdown 预览与超长会话流式显示；提升电脑休眠唤醒后的恢复能力 https://www.codebuddy.cn/docs/workbuddy/Changelog

## 阿里 QwenPaw
- v2.2.1（09-11）：支持为每个 Agent 分别配置模型路由，包含 provider 偏好与 fallback 行为；新增 Auto Fin 主动记忆复盘并升级 ReMe；PowerContext 作为可选长期记忆后端，可在 Console 中配置 https://github.com/agentscope-ai/QwenPaw/releases
- v2.2.1（09-11）：QwenPaw Creator 1.2.0 新增蓝图工作台、多时间线对比、可复用视频模板、MiniMax H3 支持、项目快照回滚与 Docker 部署 https://github.com/agentscope-ai/QwenPaw/releases
- v2.2.1（09-11）：Console 与工作区统一环境变量设置页（Agent/MCP/工具/本地模型共用），支持插件与 PawApp 更新检测及一键安装；技能可预加载完整指令，并在使用前校验版本与依赖 https://github.com/agentscope-ai/QwenPaw/releases
- v2.2.1（09-11）：安全与运行时：安全关键发现默认需人工批准、MCP 工具白名单在 Agent 运行时强制执行、浏览器安装移出启动路径、超长对话折叠已消费的思考内容 https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw
- 2026.9.4（09-11）：插件集中管理，可浏览内置与 ClawHub 插件并从 Control UI 安装、配置与授权；按类别浏览已安装插件，统一搜索技能 https://github.com/openclaw/openclaw/releases
- 2026.9.4（09-11）：预备云会话，符合条件的本地 Git 项目与公开 GitHub 仓库会话可复用已预备 worker，默认每项目/配置保留一个、全 Gateway 上限四个；预备 worker 会持续产生 provider 机器运行费用 https://github.com/openclaw/openclaw/releases
- 2026.9.4（09-11）：更新回滚与恢复，兼容失败的更新会恢复保留的包、命令 shim、服务与激活前配置并复核旧 Gateway；数据库 schema 迁移类升级仍需验证过的备份 https://github.com/openclaw/openclaw/releases
- 2026.9.4（09-11）：终端内支持键盘选择、自由文本回答与多问题提示，可用 /question 重新打开待答问题；新增 GPT Image 2.5 的 Flare 与 Sunburst 变体；改进会话历史恢复、语音委派结果回传与 OPENCLAW_CONFIG_READONLY 外部托管配置 https://github.com/openclaw/openclaw/releases
