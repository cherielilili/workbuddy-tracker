# AI Agent 赛道日报 2026-10-16

## 摘要
今日赛道动态密集：腾讯 WorkBuddy 一周内连发三个版本，其中 5.8.0 为功能型大版本，新增 Buddy 应用挂件、独立文件浏览器、资料库增强等能力；阿里 QwenPaw 发布 v2.2.2 稳定版，带来 Console 工作台、PawPort 迁移工具与 Hub 模型网关；开源项目 OpenClaw 推出 2026.10.10-beta.1，聚焦云会话与 Gateway 性能。Stanford HAI 活动日历新增多场研讨与会议安排。

## 重大信号
- [Tencent] WorkBuddy 5.8.0 大版本发布（10-09），随后 5.8.1（10-11）、5.8.2（10-16）连续修复迭代，详见 https://www.codebuddy.cn/docs/workbuddy/Changelog
- [Alibaba] QwenPaw v2.2.2 稳定版发布（10-15），新增 Console 与多文件夹工作区、PawPort 从 Codex/Qoder 迁移、Hub 模型网关等，详见 https://github.com/agentscope-ai/QwenPaw/releases
- [Open Source] OpenClaw 2026.10.10-beta.1 预发布（10-15），云会话、重启恢复、Gemini 4 Argon 默认模型等，详见 https://github.com/openclaw/openclaw/releases

## 腾讯 WorkBuddy
- 5.8.2（2026-10-16）：修复历史会话无法打开、企业微信机器人文件未发回对话、产物栏计数跳变、旗舰版侧边栏菜单配置不生效、语音输入连续点击异常等问题。来源：https://www.codebuddy.cn/docs/workbuddy/Changelog
- 5.8.1（2026-10-11）：安全中心文件备份支持单文件大小上限；语音输入自动聚焦与结束；企业微信助理回复跟随交流语言并可直接唤起客户端；侧栏菜单按企业后台配置排序；大量企业微信、腾讯文档、Office 预览与内存泄漏修复。
- 5.8.0（2026-10-09）：新增 Buddy 应用内嵌挂件（侧栏独立窗口打开并带入页面内容）；独立文件浏览器窗口；资料库支持助手搜索与压缩包上传；设置搜索与未登录配置代理；模型繁忙度展示；对话后下一步问题推荐；自定义模型域名风险提醒；任务失败分层提醒；Markdown/CSV/HTML 产物工具栏统一；技能云端同步与千级技能管理优化；长会话加载与流式展示优化。

## 阿里 QwenPaw
- v2.2.2 稳定版（10-15）发布，由此前 beta 系列转正：新增 Console 与 Workspaces（六套主题、多标签终端、多文件夹工作区保存为 Agent 默认）；QwenPaw-Flash 本地推荐 9B/27B/35B-A3B；PawPort 支持从 Codex 与 Qoder 导入会话、记忆、技能、插件、MCP 配置、项目与定时任务；Creator 升级 2.0.1、Data 升级 0.3.0（分析工作区与 /data 命令）；统一模型发现与定价；新增 Hub 模型网关（组织模型集中管理、成员 token 预算、用量看板）；新增 view_audio 音频理解工具；技能可批量分发至工作区并支持自定义渠道；Skill Market 源（QwenPaw、ClawHub、ModelScope、Aliyun）可作为插件安装；飞书思考面板折叠、Telegram Markdown 表格原生渲染。来源：https://github.com/agentscope-ai/QwenPaw/releases

## OpenClaw（开源）
- 2026.10.10-beta.1 预发布（10-15）：Gateway 性能大幅提升（SQLite 与主线程负载转移至 worker 线程）；升级流程可靠性修复（失败不再留下半安装状态）；中断回复与会话在 Gateway 重启后可恢复；云会话支持本地与云端互迁、按仓库组织环境与快照进度展示；Windows 桌面端与新装 Tauri 可运行本地 Gateway；新模型：Gemini 4 Argon 成为默认 Gemini 模型，新增 Nemotron 3.5 Super VL 与 xAI Imagine Image 2.0，Meta 模型经 Muse Code 运行；Apple 平台要求提升至 macOS/iOS/Safari 26.2；实验性 PostgreSQL Workboard 存储引擎；Bun 运行时支持。来源：https://github.com/openclaw/openclaw/releases
- 同期发布 2026.10.5-beta.4、2026.10.4 与 2026.9.33 等版本。
