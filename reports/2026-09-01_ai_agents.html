AI Agent 赛道日报 2026-09-01

摘要

今日赛道出现两条重磅动态：Manus 官方宣布恢复独立运营，结束此前并入 Meta 的阶段；开源项目 OpenClaw 发布 2026.8.2 稳定版，带来 Home 面板停靠、Linux 桌面端等多项新能力。此外阿里 QwenPaw 发布 2.2.0 第六个 beta 预发布版，以修复与测试加固为主。

Manus

  • 官方博客 09-01 发布《Manus Resumes Independent Operations》，宣布 Manus 将作为独立 Agent 实验室恢复独立运营，并表示将继续推动通用 AI Agent 能力边界、将新能力转化为产品。此前 Manus 曾于 2025-12-29 宣布加入 Meta，此次回归独立是重大公司层面信号。来源：https://manus.im/blog

Open Source / OpenClaw

  • 发布 2026.8.2 稳定版（09-01，Latest）：新增 Home 对话可停靠于右侧或底部面板（Cmd/Ctrl+Shift+H），不离开当前页面即可使用；首次推出 Linux 桌面伴侣（.deb/AppImage，x86-64），支持系统托盘 Quick Chat 与 X11 快捷键，AppImage 更新经签名校验；支持从 New Session 直接创建并运行后台会话；升级安全性增强（保留较新配置、阻止不完整会话迁移、更新失败后可恢复 Gateway）；修复工具调用后无最终回复、语音播报混入内部推理等问题；新增免 Gateway 的 Chrome 扩展本地中继唤醒；新增 CRT、Manuscript、Rosé、Miami 四套 Control UI 主题。另注意此前误标为 2026.9.1-beta.1 的版本已更正为 2026.8.1-beta.4。来源：https://github.com/openclaw/openclaw/releases

阿里 QwenPaw

  • 发布 v2.2.0-beta.6 预发布版（09-01）：桌面端打包 ReMe 入口插件；控制台单测扩充 617 例、语句覆盖率提升 10.61 个百分点；新增助理文本复制时去除推理内容；钉钉宽屏卡片开放 card_auto_layout 开关；修复治理层 shell 行续接绕过敏感路径检查、记忆模块 ReMe 启动时序、截图保存目录等问题。以修复与测试加固为主，属常规迭代。来源：https://github.com/agentscope-ai/QwenPaw/releases
