## OpenClaw（开源）
- 2026.11.10-beta.3 预发布（2026-11-24 03:28 UTC）：[releases](https://github.com/openclaw/openclaw/releases)
  - 更新恢复：跨 schema 变更或机器重启导致的中断更新保持可恢复，安装目录按发布版本隔离
  - 委派任务可靠性：子 Agent 的完成结果在 Gateway 重启、父级轮转、兄弟任务仍在运行时仍可取回，投递失败改为显式暴露而非静默丢弃
  - 子 Agent 指令注入：运行中的子 Agent 能更快接收新指令，重试时保留原始任务说明
  - 长会话性能：压缩或打开超大历史记录时降低内存与主线程开销
  - 凭据与附件：编辑设置时保留 SecretRef 凭据，避免下载 Signal 阅后即焚附件
  - Provider 登录：可在浏览器完成 OpenCode Console / OpenCode Go 登录并发现账号可用模型，模型清单刷新不再依赖 OpenClaw 发版
  - 插件侧问答：插件可 fork 实时会话上下文执行隐藏后台轮次，受 session 策略治理的文件访问与执行权限约束
  - MCP 配置：CLI 保存的 MCP server 变更无需停止 Gateway 即可生效
  - 边界修复：管理员权限跨原生客户端保留、已移除的 Discord DM 发送者不再借旧会话绑定继续投递、实时语音流绑定已签名通话、Telegram owner 身份与会话归属保持
- 发布标签侧新增 2026.11.8 稳定版（较上次记录的 2026.11.7 前进一版），抓取内容未展开该版本的具体变更说明。
