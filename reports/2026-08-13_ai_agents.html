摘要

今日赛道有两条重磅动态：阿里 QwenPaw 结束近一个月的 beta 迭代，正式发布 v2.1.0 稳定版，带来 OS Shell 桌面环境、统一文件工作区与视频创作 Agent 套件；Manus 官方发布致用户信，宣布即将恢复为独立公司运营，公司层面出现重大变化。其余监控源无新增动态。

重大信号

  • [Alibaba] QwenPaw v2.1.0 正式版发布：OS Shell、统一文件工作区、QwenPaw Creator 视频 Agent、跨 harness 集成与 Computer-use 全面落地（https://github.com/agentscope-ai/QwenPaw/releases）
  • [Manus] 官方博客发布《A Note to Our Users》，宣布 Manus 即将恢复独立公司运营，并提示用户账号可能需要操作（https://manus.im/blog）

阿里 QwenPaw

  • v2.1.0 正式版今日发布（此前最新为 v2.1.0-beta.2，期间快速迭代了 beta.3/beta.4/beta.5）。核心更新：
  • 新增 QwenPaw OS Shell：应用以可移动、可缩放窗口运行，含启动器、任务栏、通知与布局保存；应用中心与 OS Shell 统一应用目录
  • 统一文件工作区：在 Chat 内直接浏览、预览、编辑、对比、上传下载工作区文件，支持 Robot Framework 语法高亮
  • QwenPaw Creator：多 Agent 协作的视频创作能力，支持剪辑、字幕、特效、配音、并行生产流程，新增设置中心与外部 Skills
  • 跨 harness 集成：可创建由 Codex 或 Qoder 驱动的 Agent，ACP 客户端支持临时模型、项目目录与 MCP 服务透传
  • Browser-use 保持 Beta；Computer-use 新增 Windows 桌面应用自动化，macOS 打包签名完成
  • 上下文与长任务：会话/记忆/工作区快照恢复、长对话历史可搜索索引、Visual Compact、后台长任务进度管理
  • 渠道：飞书、QQ、企微、小艺、元宝支持自定义网关端点，便于私有化部署
  • 来源：https://github.com/agentscope-ai/QwenPaw/releases
