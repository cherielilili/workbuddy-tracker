## Open Source / OpenClaw
- **2026.9.2 版本发布（09-05）**，核心变更如下（来源：https://github.com/openclaw/openclaw/releases）：
  - **GPT-6 Astra 模型支持**：可选 openai/gpt-6-astra，支持 OpenAI API Key 或符合条件的 ChatGPT/Codex 账户接入，覆盖文本与图像输入、Responses 工具调用及推理控制；并支持异步函数工具、基于缓存 WebSocket 的响应中途引导（steering），以及 /think ultra 推理编排。
  - **Swarm 默认开启**：并发子智能体编排转为默认能力，提供结构化结果与实时进度，同时保留显式退出与工具限制。
  - **会话可靠性**：Gateway 重启后可恢复进行中、排队及委派的回复；续聊指令在上下文压缩与重试中保持一致。
  - **性能优化**：长会话与磁盘占用处理移出 Gateway 事件循环，聊天、仪表盘与会话交互响应更快。
  - **升级与备份**：自动更新保留已启用技能与默认 Agent 归属，Git 更新后 Gateway 可正常重启；Git 备份完整保留含 NUL 字符文本，拒绝损坏的归档头。
  - **配置热更新**：更多 Agent、模型、工具、渠道、浏览器等设置无需重启 Gateway 即可生效。
  - **实验性功能**：插件自定义 UI（Settings → Labs）、Apple Watch 独立 Talk 模式、Slack Block Kit 富回复、个人多账户连接（Settings → Profile）。
