# AI Agent 赛道日报 2026-10-26

## 摘要
腾讯 WorkBuddy 在 24 小时内连发 5.9.1 与 5.9.2 两个版本，5.9.1 带来跨设备任务/空间/定时任务一键迁移、Buddy One 会员购买入口、Gmail 部分授权与云端记忆增强，5.9.2 则以语音识别、快捷键与本地文件保存等修复为主。开源侧出现面向 NVIDIA DGX Spark 的 NemoClaw + vLLM 全流程实操教程，把 OpenClaw Agent 放进内核级沙盒并实现全本地推理，私有化部署门槛进一步降低。

## 重大信号
- [Tencent] WorkBuddy 发布 5.9.1（2026-10-22）：新增同账号跨设备导入任务、空间与定时任务，新增 Buddy One 会员购买入口，新增 Gmail 部分授权与补充授权后自动回跳客户端，云端记忆可记住项目相关内容，视频生成等高积分工具在完全访问模式下也需二次确认 — https://www.codebuddy.cn/docs/workbuddy/Changelog

## 腾讯 WorkBuddy
- 5.9.2（2026-10-26）：语音识别终稿直接回填输入框、不再二次润色；恢复语音组合快捷键并与双绑定设置同步；修复欢迎页办公/开发模式路由在版本切换后失效、本地文件保存与另存为异常、云会话停止生成后回车误发、无产物时 MCP 应用面板被空白标签页替换，以及深色模式下专家卡片付费标签与 Buddy One 推荐卡背景不可辨认等问题 — https://www.codebuddy.cn/docs/workbuddy/Changelog
- 5.9.1（2026-10-22）：新增跨设备一键迁移任务、空间与定时任务；新增 Buddy One 会员购买并同步更新排队提示；新增 Gmail 部分授权流程；新增 macOS 本地会话上传 HEIC 图片；优化云端记忆对项目相关内容的记忆能力；优化 PPT 生成素材核对以减少图文不符；优化本地服务链接与 HTML 预览改在内置浏览器和新页签打开；修复专家团任务完成后显示运行中或已中断、子成员状态错乱、历史任务顺序错乱、Markdown 预览编辑被旧内容覆盖、工作区授信误判导致命令无法执行等多项问题 — https://www.codebuddy.cn/docs/workbuddy/Changelog
