## OpenClaw
- 11-19 发布 **2026.11.10-beta.1**（预发布），主要亮点：
  - Agent 模板：可直接从 ClawHub 包添加 Agent，仅需单个 `CLAW.md` 清单与随包技能目录，走原生信任流程；
  - OpenClaw ID：通过 ID 隧道连接节点，在 Access 中审批，并把属主设备绑定到自有身份；
  - 浏览器接管：可在 Browser 面板直接接管 Agent 的浏览器而不中断其运行；
  - 聊天控制：运行中下发补充指令、编辑排队消息，应用重启后保留输入草稿；
  - 更新与状态：支持配置自动更新排期并由待安装版本自行预演；Gateway 状态改为启动时 copy-and-swap 迁移；macOS 上后台命令跨 Gateway 重启保持运行；
  - 权限与发现：新增沙箱会话工具的 guest 成员角色；可选启用按使用频率排序的工具索引（含 MCP 工具）；
  - 修复向：OpenClaw ID 成员权限在 HTTP 历史与连接应用面板的一致生效、子 Agent 结果跨重启保留与重投、Slack/Discord/Signal 消息投递边界、冷会话压缩 CPU 与延迟回归等。[来源](https://github.com/openclaw/openclaw/releases)
