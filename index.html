开源 / OpenClaw

  • 发布 2026.11.3 稳定版（11-10 18:53 UTC）。新增能力为零，全部为修复：私有子任务完成结果不再混入流式对话回复；父任务取消子任务后可继续交接替换工作，不再被已取消子任务的完成回执阻塞；未被应答的工具失败会显式上报，而非静默当作成功结束；provider 鉴权在运行截止时间强制中断并向下传播取消；全访问模式下沙箱图像预览仍限制在允许目录内；工作区迁移前校验证书、保留已保存的节点证书指纹。
  • 凭据隔离面向插件层加固：复用与缓存的插件结果按连接凭据隔离，其他插件的传输钩子限定在 provider 源；Firecrawl 搜索/抓取密钥与 Exa 错误中的密钥均做脱敏；托管 Signal 守护进程与内置语言服务器不再继承无关的 Gateway 密钥。
  • Gateway 与更新链路：减少启动期模块文件加载开销，修复中止命令检测遇长标点串时卡顿；profile 更新可识别自身维护锁，包存在性检查超时后需重新确认目录身份才替换并保留回滚；定时任务 cron 存储失败不再导致 Gateway 退出。
  • 渠道与终端：Twitch IRC 内容不再写入解析错误日志，多笔 Tlon 审批待处理时强制显式请求 ID；终端会话的 /reset soft 改为转发至 Gateway 而非硬重置；Git 修复流程保留不确定失败状态。
  • 链接：https://github.com/openclaw/openclaw/releases
